# GitHub 风格实体顶栏设计

## 目标

- 把当前顶部导航从“悬浮毛玻璃卡片”改成更接近 GitHub 的实体顶栏。
- 只调整顶栏外层骨架、材质和页面顶部留白，不改内部控件逻辑。
- 保持桌面端和移动端的导航行为、搜索行为、主题切换行为都不变。

## 非目标

- 不重做搜索框、导航项、主题切换本身的交互和结构。
- 不处理页面主体里的玻璃材质，只处理顶栏外层。
- 不顺带改动其他已有未提交文件，尤其不碰 `src/components/ui/DropdownSelect.vue`。

## 当前问题

- `TopHeaderLayout.vue` 现在用的是上方留白 + 大圆角 + 模糊毛玻璃卡片，视觉上更像一块悬浮层。
- 这种材质和 GitHub 那种“贴顶、实体、带细分隔线”的导航感差异很大。
- `App.vue` 里的 `padding-top` 也是按当前悬浮顶栏高度算的，改成实体顶栏后需要一起收紧。

## 方案对比

### 方案 A：只改外层实体骨架

- 顶栏改成贴顶的整条实体导航条。
- 去掉外层圆角、模糊、玻璃渐变和悬浮阴影。
- 保留内层控件和交互不变。

这是本次采用的方案。改动最小，最符合“只改骨架，不改逻辑”的约束。

### 方案 B：外层和内层控件一起实体化

- 除了外层顶栏，搜索框、导航胶囊、按钮层级也一起改。

这种方式更完整，但会扩大范围，不符合这次只动外层骨架的约定。

## 设计决策

### 1. 顶栏外层改成贴顶实体条

- `TopHeaderLayout.vue` 的 `.topbar` 改为直接承载实体背景和底部分隔线。
- 顶栏不再保留顶部额外留白，直接贴住页面顶部。
- 继续保留 fixed 顶栏和滚动隐藏行为，不改现有隐藏逻辑。

### 2. 去除悬浮玻璃质感

- `.topbar__inner` 不再承担玻璃卡片职责。
- 去掉大圆角、毛玻璃、径向高光和悬浮阴影。
- 内层只负责宽度约束、横向布局和密度控制。

### 3. 顶栏视觉改成 GitHub 式层级

- 顶栏外层使用稳定的实体背景色。
- 用一条清晰但不抢眼的底部分隔线把导航和页面正文分开。
- 暗色模式也保持同样的实体层级，而不是半透明漂浮感。

### 4. 同步页面顶部留白

- `App.vue` 里的 `.layout` 顶部留白改为匹配新实体顶栏高度。
- 移动端断点下同样同步，避免内容被遮住或首屏留白过大。
