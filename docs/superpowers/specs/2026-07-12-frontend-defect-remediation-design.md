# 前端缺陷修复设计

## 目标

修复 `dogfood-output/report.md` 中确认的 10 项前端缺陷，保持现有“编辑部报刊”视觉方向，不扩展无真实需求的新产品模块。

## 范围与原则

- 保留当前工作区已有的前端改版，不回退用户未提交的修改。
- 修复应落在现有 Vue 3、Vue Router、Pinia 与服务层结构内。
- 行为修复先补失败测试，再写最小实现。
- 视觉修复继续使用现有设计令牌，重点改善可读性与响应式稳定性。
- 不虚构文档、API、GitHub、Email 或 RSS 地址；没有真实目标的入口直接移除。

## 功能设计

### 1. 公开作者主页

新增 `/author/:id` 路由和公开作者视图。文章页作者入口传入文章作者 ID，公开作者页从现有文章数据中提取作者资料，并展示该作者的公开文章。找不到作者时显示明确空状态与返回文章列表入口。

`/about` 继续只承担当前用户的登录入口和个人中心，不再复用为文章作者主页。

### 2. 恢复文章评论区

在文章正文与返回列表链接之间挂载现有 `CommentSection`，传入当前文章 ID。保留现有登录门槛、评论加载、回复、点赞、举报与失败状态逻辑。文章不存在或仍在加载时不创建评论区。

### 3. 筛选重置状态

文章列表的“存在活动筛选”判断覆盖日期、关键词、排序方式和每页数量。只要任一值偏离默认状态，“重置”按钮即可用；重置后恢复默认值并清除对应 URL 参数。

### 4. 移动搜索弹层键盘行为

搜索弹层打开时：

- 将焦点移入搜索输入框。
- 保存打开前的焦点，关闭后恢复。
- Escape 关闭弹层。
- Tab 与 Shift+Tab 在弹层可聚焦元素之间循环，不进入底层页面。
- 弹层使用对话框语义，向辅助技术声明模态状态。

### 5. 未知路由兜底

新增通配路由和 404 页面。页面显示“页面不存在”、当前路径提示、返回首页和浏览文章两个恢复入口。无效文章仍保留“未找到文章”语义，但补充返回文章列表操作。

### 6. 注册资料时间与默认状态

注册页的用户协议默认不勾选。Mock 注册用户的 `createdAt` 继续由注册时生成，并通过认证用户/资料服务传递到个人中心。移除 `AboutView` 和 Mock 资料回退中的固定 `2024/05/12`；新用户关注数默认设为 0。

现有旧会话缺少创建时间时，使用登录时间或当前时间作为兼容回退，不再展示虚构历史日期。

### 7. 主题与资料头部对比度

调整暗色主题的正文弱化色、页脚文字和卡片元信息，使其与背景保持清晰区分。个人中心封面上的用户名和元信息改用适合深色渐变背景的浅色文字，并增加必要的文字阴影或半透明承托层。

### 8. 页脚占位入口

移除“文档”“API”及三个无目标社交链接。保留首页、文章、写作和真实可用的站内入口。页脚布局在资源列移除后重新平衡桌面与移动端列数。

### 9. 注册协议主动确认

协议复选框初始值为 false。空表单提交时继续显示现有校验信息；用户主动勾选后才允许注册流程通过。

### 10. 首页头条摘要排版

移除桌面头条摘要的多栏排版，使用单栏、合理最大宽度和稳定行高。摘要文本保持 DOM 顺序与视觉阅读顺序一致，桌面和移动端只通过宽度调整响应式表现。

## 组件与数据流

- `Article.vue`：作者链接改为公开作者路由，并挂载评论区。
- `AuthorView.vue`：根据路由作者 ID 获取公开文章和作者资料。
- `ArticleListView.vue`：统一判断默认查询状态。
- `MobileSearchSheet.vue`：负责模态键盘交互和焦点恢复。
- `NotFoundView.vue` 与路由：处理未知地址。
- `useAuthStore`、`profileService`、`AboutView`：贯通真实创建时间和默认资料。
- `TopFooter.vue`：只渲染可用入口。
- `base.css`、`AboutView.vue`、`HomeView.vue`：处理对比度与摘要排版。

## 错误与空状态

- 作者不存在：显示作者未找到，并提供返回文章列表入口。
- 文章不存在：显示文章未找到，并提供返回文章列表入口。
- 评论加载失败：沿用评论区现有错误状态。
- 未知路由：始终显示 404 恢复页面，不出现空白正文。
- 缺少旧账号创建时间：使用可解释的兼容回退日期。

## 测试策略

- 路由测试：公开作者路由与通配 404 路由存在且指向正确视图。
- 文章测试：作者链接包含作者 ID，评论区收到文章 ID，文章未找到时存在恢复入口。
- 筛选测试：排序或每页数量变化会启用重置。
- 搜索弹层测试：Escape、焦点循环和焦点恢复。
- 注册测试：协议默认未勾选且校验阻止提交。
- 资料测试：注册时间来自真实用户数据，新用户关注数为 0。
- 页脚测试：不存在 `href="#"` 占位入口。
- 样式/结构测试：首页摘要不再使用多栏，资料封面文字使用高对比度样式。
- 最终运行 ESLint、全部 Vitest、类型检查、生产构建，并用浏览器复测桌面端和移动端。

## 非目标

- 不新建文档站、API 门户、RSS 服务或外部社交账号。
- 不重写认证、评论或文章服务架构。
- 不重新设计整站视觉体系。
