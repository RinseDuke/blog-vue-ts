# Write 页面底部状态栏材质统一设计

## 目标

- 保持 `write` 页底部状态栏继续固定在浏览器底部。
- 让底部状态栏和 `发布设置` 面板使用同一套材质层级，减少深浅模式下的割裂感。
- 不改变现有交互语义，只调整结构、层级、间距和视觉表现。

## 现状问题

- 状态栏当前是一整条扁平色块，和上方 `PublishPanel` 的卡片式材质语言不一致。
- 模式切换下拉菜单的背景、边框和阴影与状态栏、发布设置并不统一。
- `Write.vue` 底部留白只够旧状态栏高度，新材质状态栏增加后容易压住正文视觉呼吸区。

## 设计决策

### 1. 固定底栏保留，但改为双层结构

- 外层 `status-bar` 只负责固定定位和轻量过渡背景。
- 内层增加与内容宽度对齐的 `status-bar__inner`。
- 主体交互条收敛到 `status-bar__shell`，复用与 `PublishPanel` 接近的圆角、边框、阴影和毛玻璃层次。

### 2. 统一材质变量

- 在 `src/assets/base.css` 抽出 write 页面共用面板变量。
- `PublishPanel` 与 `StatusBar` 都使用相同的卡片背景、描边和阴影 token，避免两个组件后续再次分叉。

### 3. 按钮和菜单统一为“嵌入式控件”

- 普通操作按钮改成低对比胶囊按钮，hover/focus 使用同一套 surface 过渡。
- 发布按钮保留品牌强调色，但边框半径、内阴影和 hover 强度要和整体材质协调。
- 模式菜单改为和卡片同源的浮层风格，避免菜单像另一套系统。

### 4. 适配正文留白

- `Write.vue` 底部安全区从旧的 `36px` 提升到新的状态栏高度，保证固定底栏不压内容。
- 移动端进一步压缩操作密度，但仍保留统一材质。

## 影响文件

- `src/assets/base.css`
- `src/components/post/PublishPanel.vue`
- `src/components/post/StatusBar.vue`
- `src/views/Write.vue`
- `AGENTS.md`
