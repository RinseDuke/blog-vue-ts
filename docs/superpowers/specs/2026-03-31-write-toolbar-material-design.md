# Write 页面顶部工具栏材质统一设计

## 目标

- 让 `write` 页顶部工具栏和底部状态栏、发布设置保持同一套材质语言。
- 保留当前“所有工具直接可见”的使用方式，不改变操作入口和排序。
- 优化浅色 / 深色 / 移动端下的层级、间距和粘性吸顶表现，减少割裂感。

## 现状问题

- 顶部工具栏目前是扁平条状结构，和已经卡片化的底部状态栏、发布设置不在同一材质层级。
- 分组依赖硬分隔线，按钮默认态、悬浮态、激活态都偏散，缺少统一的 surface 约束。
- 移动端虽然功能都在，但多行换行后的密度较高，视觉边界不够稳定。

## 方案选择

### 方案 1：保留全量直显，仅统一材质与层级

- 不改工具数量和功能分组顺序。
- 改造工具栏外层容器、分组包裹、按钮状态和吸顶表现。
- 让按钮、分组容器和 sticky 工具栏都复用 write 页既有 surface token。

这是本次采用方案，因为学习成本最低，也最符合当前写作流程。

### 方案 2：移动端横向滚动工具带

- 可以进一步压缩移动端高度。
- 但会牺牲“全部一眼可见”，不符合当前确认方向。

### 方案 3：双层工作台

- 视觉更强，但会让控制层过重，容易压正文。

## 设计决策

### 1. 工具栏容器改为卡片式 sticky surface

- 保留吸顶，但从扁平条改为带圆角、柔和边框、轻阴影、轻模糊的浮层卡片。
- 工具栏与标题、正文之间维持明确但平滑的层级递进。
- sticky 时仍保持稳定，不做夸张位移动画，只保留轻微材质过渡。

### 2. 分组从“硬分隔线”改为“轻分组胶囊”

- 每组工具外包一层低对比度 group surface。
- 竖向分隔线只保留在组内节奏需要处，整体弱化。
- 这样能保留原本信息结构，同时减少零散感。

### 3. 按钮统一为小型 surface control

- 默认态：低对比背景 + 清晰边框。
- hover：轻微提亮，不跳色。
- active：品牌色染色，但控制对比和阴影，避免脱离整体。
- disabled：降权但保留可识别性。

### 4. 移动端继续全量直显，但收紧密度

- 保持所有工具可见。
- 通过更紧凑的 group padding、按钮尺寸和行间距控制多行布局。
- 避免出现按钮块状大小不一或换行后边界断裂。
