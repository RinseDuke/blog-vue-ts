# Frontend Redesign Design

## Goal

在不改变现有文章、搜索、登录、注册、个人中心、写作和评论业务逻辑的前提下，全面重新设计前端 UI 和页面排版。

## Visual Direction

采用「Signal Lab」方向：界面更像技术写作控制台和内容信号系统，而不是暖色内容站或柔和 Apple/GitHub 蓝色毛玻璃风格。

- 标题字体使用 `Sora`，正文使用 `IBM Plex Sans`，编号、眉题和状态信息使用 `JetBrains Mono`。
- 主色从纯蓝和暖色内容站调性转为石墨、青绿信号色、琥珀状态色和少量品红强调色。
- 卡片、按钮、菜单、筛选器和工具面板统一使用 8px 内的半径 token，视觉上更接近控制台面板。
- 背景使用线性数据网格、玻璃面板边线和冷色光感，不使用装饰光球、bokeh 或 radial orb。
- 显式 `letter-spacing` 统一为 `0`，避免标题和按钮在中英文混排时出现挤压或溢出。

## Page Layout Scope

- 首页：使用项目内 bitmap 资产 `src/assets/signal-lab-hero.png` 作为最新文章主视觉，保留现有 `usePostsStore` 数据流。
- 文章列表：改为“内容矩阵”控制台排版，保留 URL query、筛选、排序、分页逻辑。
- 个人中心：保留个人资料、草稿、动态和编辑简介逻辑，只更新视觉层级、侧栏和按钮样式。
- 登录/注册：保留现有校验、登录、注册、跳转和密码可见性逻辑，只更新品牌面板和表单样式。
- 搜索、导航、下拉、日期选择、文章筛选、写作工具栏、评论面板：清理旧蓝色、光球、胶囊圆角和 tracking，统一到新设计 token。

## Boundaries

- 不新增角色、权限、用户管理、后端接口或业务状态。
- 不改写 Pinia store 的行为，不改变 service 请求协议，不改变 router 守卫语义。
- 不新增营销落地页，第一屏仍是可用的内容列表体验。
- 不引入新 UI 库。

## Verification

- 源码扫描应证明 `src` 中没有 `radial-gradient(circle...)` / orb 装饰模式。
- 源码扫描应证明 `src` 中没有显式负值或非零 `letter-spacing`。
- 测试、类型检查、lint 和 build 必须通过。
- 浏览器预览需要检查桌面和移动视口的首页、文章列表、个人中心、登录/注册、写作页或共享导航，不出现明显重叠、裁切和不可读文本。
