# 文章编辑器逐行实时预览设计

## 目标

- 将文章正文改为以轻量标记源码作为唯一内容，编辑、保存、导出和发布都不再经过富文本反向转换。
- 实现接近笔记软件的逐行实时预览：光标所在行显示原始标记，其他行隐藏常用标记并呈现排版。
- 当前行不增加选中框，标记符号使用浅色，正文继续使用网站正常文字色。
- 编辑区、阅读预览和文章详情统一使用网站现有正文、标题和等宽字体变量。
- 支持常用扩展，并补充代码高亮、脚注、数学公式、目录和流程图。

## 方案选择

### 方案一：继续扩展现有富文本编辑器

可以复用现有工具栏，但正文会持续经过页面结构与轻量标记源码双向转换，扩展语法容易丢失，逐行预览也很难与源码位置保持一致。

### 方案二：改为源码编辑器

轻量标记文本始终是唯一内容，编辑器只通过装饰层控制显示。光标移动、撤销重做、选区和键盘输入都由成熟编辑器处理，适合逐行实时预览和后续扩展。

本次采用方案二。

## 编辑器结构

- 新增独立的实时预览组件，内部使用源码编辑器。
- 组件接收和更新轻量标记字符串，不生成中间页面结构作为编辑数据。
- 光标所在逻辑行保留全部标记，标记符号使用较浅颜色，正文使用网站正文颜色。
- 非活动行隐藏标题、强调、链接、列表、引用、任务列表等常用标记，并保留对应排版。
- 工具栏不再直接操作富文本节点，而是对当前选区插入或切换标记。
- 源码模式继续保留，用于查看完整原文；阅读模式使用统一预览组件。

## 内容渲染

- 基础语法与常用扩展：标题、强调、删除线、链接、图片、表格、任务列表、引用、代码和分隔线。
- 技术写作扩展：
  - 代码块语法高亮。
  - 脚注。
  - 行内和块级数学公式。
  - 自动标题锚点与目录。
  - 流程图。
- 所有生成内容在显示前净化，链接使用安全属性。
- 写作页阅读模式和文章详情共用同一套渲染逻辑，避免发布前后效果不同。

## 字体

- 普通正文使用网站正文变量。
- 标题使用网站标题变量。
- 标记符号和代码使用网站等宽字体变量。
- 不单独加载新的远程字体，继续沿用网站当前系统字体栈。

## 兼容与迁移

- 旧草稿仍读取原有轻量标记字段。
- 历史原始表格结构继续在读取时转换为标准表格语法。
- 发布接口仍提交源码与渲染结果，后端数据结构不变。
- 移除写作页对旧富文本编辑器和旧实时预览插件的依赖，不改动其他页面的数据层。

## 测试与验证

- 为扩展渲染、内容净化和旧表格迁移补充单元测试。
- 为工具栏命令补充纯函数测试。
- 为逐行实时预览组件补充结构和交互测试。
- 运行相关测试、完整测试、类型检查和生产构建。
- 在桌面与移动端检查浅色、深色、光标逐行移动、源码模式和阅读模式。
