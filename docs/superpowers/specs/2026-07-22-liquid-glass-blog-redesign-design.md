# Liquid Glass Blog Redesign Design

## 目标

在不改变现有路由、文章、搜索、认证、个人资料、评论和写作业务逻辑的前提下，将博客前端更新为接近苹果液态玻璃语言的现代界面，并同时保证桌面端与移动端的可读性、响应速度和完整可用性。

## 视觉方向

采用克制的液态玻璃风格，而不是把所有内容都放进高模糊透明面板。

- 页面背景使用低饱和灰蓝色渐变、柔和光感和少量层次纹理，为透明表面提供可感知的折射背景。
- 导航、精选文章、筛选器、弹层、表单和辅助工具使用半透明玻璃表面，包含背景模糊、细边缘高光、内侧亮边和柔和阴影。
- 正文、长列表和高密度编辑区域保持较高不透明度，确保阅读清晰并减少渲染负担。
- 浅色模式采用冰白与灰蓝玻璃；深色模式采用深海蓝黑玻璃，并保持相同的层级关系。
- 圆角统一但不过度胶囊化。只有状态标签、切换项和小型操作按钮使用完整胶囊形态。
- 字体与字号保持现代、清晰、克制，标题具有较强层级，正文优先保证中英文混排的阅读体验。

## 页面结构

### 全局框架与导航

- 桌面端使用悬浮玻璃导航栏，初始状态通透，滚动后缩小垂直尺寸并增强背景模糊和边界。
- 移动端使用紧凑玻璃导航，减少同时显示的入口，将次要操作放入菜单或搜索面板。
- 主题切换、登录状态、搜索和主要导航保持现有行为，只调整布局与反馈。
- 页脚使用低透明度玻璃分隔区，与正文保持清晰边界。

### 首页

- 第一屏由品牌标题、简短说明和精选文章玻璃舞台构成。
- 精选文章使用明显但克制的视觉焦点，可结合文章封面、渐变遮罩和玻璃信息层。
- 最新文章使用响应式卡片流；桌面端形成有节奏的多列布局，移动端改为单列。
- 加载、错误、重试和空状态保留完整反馈，并使用统一玻璃组件语言。

### 文章列表与搜索

- 筛选、排序、日期选择和搜索条件放入统一玻璃控制面板。
- 结果区保持高对比背景，卡片通过边缘高光、轻微上浮和阴影变化表达交互。
- 移动端筛选器采用可收起面板或底部浮层，避免占用首屏。
- 保留 URL 查询参数同步、分页、搜索建议和搜索历史行为。

### 文章详情与评论

- 正文内容使用接近实色的阅读面板，控制行宽、行高、标题间距、代码块和引用样式。
- 阅读进度、文章操作、目录和评论区可以使用玻璃表面，但不覆盖正文主体。
- 评论输入、回复、点赞、举报和错误状态保留现有逻辑，并统一焦点、禁用和提交反馈。

### 登录、注册与个人页面

- 登录和注册页面采用玻璃表单面板与柔和背景光层，表单本身保持明确边界和足够对比度。
- 个人主页使用玻璃资料卡、内容标签和文章列表，长用户名和简介必须在桌面与移动端正确换行。
- 登录校验、密码可见性、重定向、资料编辑和文章管理行为保持不变。

### 写作页面

- 工具栏、发布设置和状态栏使用玻璃表面；编辑正文区域保持稳定、低透明度的书写画布。
- 桌面端保留完整工具组，移动端允许横向滚动或分组折叠，不能遮挡正文与发布操作。
- 保留 TipTap、Markdown 模式、草稿保存、封面上传和标签管理行为。

## 动效与交互

- 首次进入页面使用短促的分层淡入和轻微位移，避免长时间或大幅度动画。
- 可交互玻璃表面在悬停时轻微上浮，并改变边缘高光与阴影；按下时提供小幅缩放反馈。
- 导航收紧、弹层出现和主题切换使用统一缓动曲线。
- 支持 `prefers-reduced-motion`，在用户减少动态效果时关闭位移、光泽移动和复杂过渡。
- 不实现持续追踪鼠标的大面积光斑，避免干扰阅读与增加移动设备负担。

## 响应式与性能

- 重点检查 1440px、1024px、768px、390px 和 360px 视口。
- 移动端减少叠加模糊层数量，必要时使用更高不透明度和更轻的阴影替代复杂折射。
- `backdrop-filter` 不可用时，玻璃组件必须回退为高不透明度表面，文字与边界仍然清晰。
- 避免在滚动内容中使用大面积持续动画和过多独立滤镜层。

## 无障碍要求

- 正文、按钮、表单和状态文本在浅色与深色模式下保持清晰对比度。
- 所有交互控件保留键盘焦点样式、可访问名称和合理点击区域。
- 透明背景不能成为表达状态的唯一方式；错误、成功、选中和禁用状态同时使用文字、图标或边界变化。
- 主题切换和弹层继续支持键盘操作与正确的焦点管理。

## 边界

- 不修改 Pinia store、service 请求协议、路由守卫和现有业务语义。
- 不引入新的 UI 框架，不新增后端接口或账户权限功能。
- 不复制苹果品牌资产或专有界面，只借鉴液态玻璃的材质、层级和动效原则。
- 不为追求玻璃效果牺牲正文可读性、移动端性能或操作清晰度。

## 验证标准

- 运行完整单元测试、类型检查、代码检查和生产构建。
- 在桌面端逐项检查：首页、文章列表、文章详情、搜索、登录、注册、个人主页、写作页、评论与共享导航。
- 在移动端逐项检查相同页面与流程，确认无重叠、裁切、横向溢出、不可读文本或无法点击的控件。
- 分别检查浅色和深色模式，以及减少动态效果设置。
- 检查加载、错误、空状态、表单校验、菜单、弹层、筛选、搜索和编辑器工具栏等关键状态。
- 检查不支持 `backdrop-filter` 时的回退表现。
